# Road Map

## Sprint 1
### Week 1-2: UX Research and Requirements 
1. Requirements Elicitation
2. UX Research
   1. Intended users
   2. Demographics
   3. Specific frustrations
   4. How each frustration is taken account of
   5. Surveys/interviews/conversations with friends and Discord members
3. Requirements Specification (discussion)

### Week 3-4: Design
1. Revise Figma Design
2. Decide on software architecture
3. Draw use case diagrams
4. Decide on accessibility

### Week 5-6: Implementation Shallow MVP
1. Decide on frameworks (if any) and tech stack
2. Implement with pair programming
   1. Driver (writing code)
   2. Navigator (not writing code, giving information and spotting bugs)
3. Refer to architecture and design

### Result of Sprint 1:
1. Decided tech stack to be Flutter for frontend and Spring Boot for backend
2. Succeeded in creating onboarding frontend (Shivesh) and minimal, dummy backend (Charles)
